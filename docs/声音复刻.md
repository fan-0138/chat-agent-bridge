# 声音复刻（让她用视频里那种声音说话）

目标：别人视频里「机器人账号」那种撒娇女声，让她在 QQ 语音条里也用这个音色。

整条路：**扒视频 → UVR5 分人声 → 剪参考片段 → GPT-SoVITS 零样本复刻 → 接进桥接**。

## 1. 扒视频和音轨

```bash
# 视频（需要登录态：用桥接那个浏览器，或者 yt-dlp 带 cookies）
# 这里当时是连 CDP 拿的：
#   CDP http://127.0.0.1:9223 → 打开视频页 → 拦 video/mp4 响应拿 URL
curl -L -b cookies.txt -o dv.mp4 "<播放地址>"
ffmpeg -y -i dv.mp4 -vn -ar 44100 -ac 2 dv441.wav
```

> 注意：抖音播放地址带时效签名，一次没用完就得重新开页面拿。

## 2. UVR5 把人声和伴奏扒干净

GPT-SoVITS 自带 UVR5（`tools/uvr5`），权重放在 `tools/uvr5/uvr5_weights/`：

- `HP2_all_vocals.pth` —— 人声/伴奏分离（默认用这个）
- `HP5_only_main_vocal.pth` —— 只留主唱/主人声（更激进，环境声一起削掉）
- `model_bs_roformer_*.ckpt` —— 质量更好、更吃 CPU

```python
import sys
sys.path.insert(0, 'tools/uvr5')
from vr import AudioPre

pre = AudioPre(agg=10, model_path='tools/uvr5/uvr5_weights/HP2_all_vocals.pth', device='cpu', is_half=False)
pre._path_audio_('dv441.wav', ins_root='out/instr', vocal_root='out/vocals', format='wav')
```

**坑**：喂 16k 单声道进去会在 resample 那步报 `Audio buffer is not finite everywhere`；
用 **44.1k 立体声** 就正常（跟 `tools/uvr5/webui.py` 的入口一致）。

分出来的 `vocal_*.wav` 就是干净人声。

## 3. 剪参考片段（3–10 秒，一个人、一句话）

> **硬限制**：GPT-SoVITS 的参考音频必须在 **3–10 秒**之间，超了直接报
> `Reference audio is outside the 3-10 second range`。想多用音色信息就**把几段拼起来**，
> 但总长压在 9.8s 左右最稳。

第二条参考视频（35s「机器人账号用户超进化」）里能用的三句（whisper 核过）：

| 段 | 时间 | 内容 |
|---|---|---|
| a | 2.60–7.60 | 完了，这肯定是小说看多了，脑子不记得放哪儿了。 |
| b | 10.70–12.70 | 果然空空的。 |
| c | 16.10–18.70 | 现在该怎么办呢？ |

24.6–34.2s 那段是人声也被分出来了，但 whisper 只认出「哎啊呀呀呀呗」，像是音效/鬼畜片段，不用。

拼接（各自响度归一 → 中间垫 0.35s 静音 → 总长 9.8s）：

```bash
ffmpeg -y -i /tmp/uvr2/vocals_hp2/vocal_dyv2-441.wav_10.wav -ss 2.60 -to 7.60 -ac 1 -ar 32000 \
  -af "loudnorm=I=-18:TP=-1.5:LRA=11" refs/v2/a.wav
# b、c 同理，然后：
ffmpeg -y -i a.wav -i gap.wav -i b.wav -i gap.wav -i c.wav \
  -filter_complex "[0][1][2][3][4]concat=n=5:v=0:a=1,loudnorm=I=-18:TP=-1.5:LRA=11" refs/v2/all.wav
ffmpeg -y -i refs/v2/all.wav -t 9.8 -af "loudnorm=I=-18:TP=-1.5:LRA=11" refs/v2/all-9.8.wav
```

`prompt_text` 要把 a+b+c 三句都写上（和音频逐字对应）。参考越短她念得越赶：
3.75s 单句那条 17 个字只用 3.9 秒，9.8s 这条同样的话用 4.66 秒，更像正常说话。

## 6. 接进桥接

`.env.qq`：

```bash
QQ_VOICE_PROVIDER=gpt-sovits
QQ_TTS_URL=http://127.0.0.1:9880/tts
QQ_TTS_REF=$HOME/Documents/deepseek/tts/voice-example/refs/v2/all-9.8.wav
QQ_TTS_PROMPT_TEXT=完了，这肯定是小说看多了，脑子不记得放哪儿了。果然空空的。现在该怎么办呢？
QQ_TTS_SPEED=1
QQ_VOICE_TIMEOUT_MS=120000     # CPU 合成慢，别用默认 25 秒
```

服务由开关脚本托管（端口 9880 探测）：

```bash
./scripts/qqbridge-ctl.sh start|stop|restart|status    # 会一起带起/关掉声音复刻
```

**回退**：把 `QQ_VOICE_PROVIDER` 删掉或设 `edge`，重启桥接，就回到微软音色；
复刻服务挂了时也可以 `QQ_VOICE_OUT=0` 一键闭嘴。

## 7. 响度（别让她像蚊子叫）

参考音频归一到了 -18 LUFS，模型也跟着学，合成出来只有 **-23.3 LUFS**；edge-tts 也只有 -22.2。
手机外放就会觉得「声音好小」。

所以两条链路的 PCM 转换那一步统一过一遍 ffmpeg：

```
-af loudnorm=I=-16:TP=-1.5:LRA=11
```

实测 silk 解回来 **-15.8 LUFS**（+7.5 dB）。想关掉：`.env.qq` 里 `QQ_VOICE_LOUDNORM=`（留空）。
太吵就改成 `I=-18`。

## 8. 情绪不够怎么办（2026-11-02 晚）

用户反馈「没有原版那么有情绪化」。零样本复刻的情绪上限基本由参考音频决定，能拧的只有这几个：

| 办法 | 效果（实测） |
|---|---|
| 采样温度 1.0 → **1.4** | 音高起伏 +0.3~0.4 半音，还不太吞字；1.5 以上开始丢字 |
| 模型 v2Pro → **v2ProPlus** | 起伏 2.41 → 2.60 半音，语气更活 |
| 加 `aux_ref_audio_paths`（撒娇参考） | 实测反而更平（1.95），且吞头词，弃用 |
| 换 v4 模型 | 本机测下来 2.49 半音，和 Plus 差不多，还更吃 CPU |
| 多生成几条挑起伏最大的 | 还没做，能再涨一点，但一条要 12 秒，翻倍等 |

现在默认：**v2ProPlus + temperature 1.4**（`.env.qq` 的 `QQ_TTS_TEMPERATURE=1.4` 可改）。
真正想「有情绪」，靠零样本不行，得 few-shot 微调——需要同一角色 1 分钟以上干净语音，
而且 M1 CPU 上训练是小时级，建议丢到有 GPU 的机器上做。

另一个可行方向：给每句话标情绪（`【语音:撒娇】`/`【语音:困】`），准备 2–3 段不同情绪的参考音频，
按标签切参考。这个思路比堆参数有效，但改动跨 prompt/桥接，得单独排。

## 9. 质量与下一步

- 现在参考 9.8 秒、三句话：合成文本 ASR 回读全对，F0 中位数 314Hz（参考视频里的人声同档）。
  短参考（3.75s）会把开头吞掉（「爸爸晚安」念没了），所以别用太短的。
- 想更像：多找几条同一角色的干净语音（每段 3–10 秒，同一人），凑 30 秒以上再做 few-shot 微调；
  或者换 `v2ProPlus` / `v4` 模型试。
- 试听样本在 `~/Documents/deepseek/tts/voice-example/samples/`。
- 官方文档：<https://github.com/RVC-Boss/GPT-SoVITS>

## 10. 自己找素材 + 微调（2026-11-02）

用户说「要你去抖音上找机器人账号系列的语音」。流程记在这，换角色也能照抄。

### 10.1 找同一个作者的全部作品

先确认两个孩子视频是谁发的，再拉作者主页的作品列表（响应拦截 `aweme/post`，比 HTML 解析稳）：

```js
// CDP 连桥接那个已登录浏览器，打开 /user/<sec_uid>，滚动 15-20 次
page.on('response', async (res) => {
  if (!/aweme\/(post|detail)/.test(res.url())) return;
  const j = await res.json();
  for (const it of j.aweme_list ?? []) posts.push({
    id: it.aweme_id, duration: it.video.duration / 1000,
    play: it.video.play_addr.url_list[0],
  });
});
```

播放地址有时效，拿到就尽快下；下载带上 `Referer: https://www.douyin.com/` + 浏览器 cookies。
这次 52 条作品，下了 32 条（8–150s），共 23 分钟素材。

### 10.2 人声分离（并行）

UVR5 单进程约 2.5× 实时，32 条要 40 分钟。开 4 个进程、每进程 `torch.set_num_threads(2)`：

```python
pre = AudioPre(agg=10, model_path='tools/uvr5/uvr5_weights/HP2_all_vocals.pth',
               device='cpu', is_half=False)
pre._path_audio_(wav, ins_root='/tmp/dyvoice/instr', vocal_root='/tmp/dyvoice/vocals', format='wav')
```

### 10.3 只留她的声音（FunASR + 声纹）

这批视频里还有 GPT/Claude 等其他角色在说话，不能一把全喂进去。三步：

1. `AutoModel(model="paraformer-zh", vad_model="fsmn-vad", punc_model="ct-punc", spk_model="cam++")`
   → 每句带时间戳、文字、说话人标签；
2. `AutoModel(model="cam++")` 给每句算 192 维声纹；
3. 和参考声纹（她已知的几段）算余弦相似度，**> 0.55 才留**。

实测：她自己 0.75–0.84，别的角色 0.2–0.4，很好分。
这次留下 **39 段 / 168 秒**，丢掉 76 段（别的角色、音效、ASR 空响应）。

### 10.4 微调（CPU 可跑，慢）

`~/Documents/deepseek/tts/voice-example/train.sh`（数据准备 + s2 + s1 三段）：

```sh
sh train.sh feature   # 1-get-text / 2-get-hubert / 2-get-sv（Pro 版本必须）/ 3-get-semantic
sh train.sh s2        # SoVITS，v2ProPlus，8 epoch，CPU 约 7 分钟/epoch
sh train.sh s1        # GPT，10 epoch
```

**踩坑**（都写进脚本了）：

- `PYTHONPATH` 要同时有仓库根和 `GPT_SoVITS/`（`text`、`feature_extractor`、`module` 三个包不在同一层）
- `gradio` 和 `gradio_client` 版本要配套：`gradio==4.44.1` + `gradio_client==1.3.0`（否则 `tools.my_utils` import 就崩）
- v2Pro / v2ProPlus 训练数据要有 `7-sv_cn`（`2-get-sv.py` 生成），否则 `TextAudioSpeakerLoader` 断言失败
- 训练输出目录 `logs/<exp>/logs_s2_<version>` 要提前建，不然最后保存权重时报 `FileNotFoundError`
- 文本分片 `2-name2text-0.txt`（以及语义分片）要合并成不带后缀的正式文件

训练完权重在 `SoVITS_weights_v2ProPlus/` 和 `GPT_weights_v2ProPlus/`，
用 `/set_sovits_weights` / `/set_gpt_weights` 热切，或者把 `tts_infer.yaml` 的 `custom` 指过去重启。

### 10.5 实测结论（2026-11-02）

微调权重训完了（`SoVITS_weights_v2ProPlus/xixi_e8_s312.pth` + `GPT_weights_v2ProPlus/xixi-e10.ckpt`），
A/B 对比同一句话：

| | 声纹相似度（vs 原视频） | 音高起伏 | 用户听感 |
|---|---|---|---|
| 预训练 + 温度 1.4（base） | 0.771 | 2.55 半音 | **更像**（选了 base-c） |
| 微调后（new） | 0.763 | 2.33 半音 | 略差 |

结论：**2.8 分钟数据微调没有提升，线上保持预训练权重**。微调权重留在磁盘上没删，
以后素材到 5–10 分钟、文本校对过再训，直接换 `tts_infer.yaml` 的路径即可。

### 10.6 风险

文本是 ASR 出来的，少量错字会让个别词发音怪；数据集只有 2.8 分钟，情绪/音色能学到但别期待翻天覆地。
真要更稳，素材上到 5–10 分钟、文本人工校对，或者上 GPU 用更大的 batch。
