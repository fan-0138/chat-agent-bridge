# 记忆

> 她会记得。不是「上下文里还留着」，是睡一觉之后还记得。

## 为什么要有这一层

以前她只有两样「记忆」：

| 东西 | 实际是什么 | 问题 |
| --- | --- | --- |
| 聊天上下文 | 最近几十轮的滚动窗口 | 一滚就没，几天前的事等于没发生 |
| `data/mind/memory.jsonl` | 她独处时选「记住」才写一条 | 实测 64 轮想法里一次都没触发 |

所以除了最近几小时，她的过去是空的。

## 三层

| 层 | 存在哪 | 什么时候写 | 谁在用 |
| --- | --- | --- | --- |
| 工作记忆 | 聊天上下文 | 每一轮 | 模型直接看 |
| 情景记忆 | `data/memory/episodes.jsonl` | 每晚整理 | 聊天/独处时按需捞 |
| 语义记忆 | `data/memory/facts.jsonl` | 每晚整理（同一件事新的盖旧的） | 同上 |

- 一条情景：`{at, day, kind, title, text, detail, people, salience, source}`
- 一条事实：`{subject: "爸爸" | "小鲸", key, value, text, at, updatedAt}`

## 两个动作

### recall —— 聊天时按他这句话捞

`src/memory-store.js` 的 `recall()` / `rankCandidates()`：

1. 把他这句话切中文二字词 + 英文/数字词，去掉「就是 / 今天 / 在吗」这类虚词；
2. 在 episodes、facts、她自己记下的事、最近一段聊天（尾巴 1200 行）里找重合；
3. 长句要 2 个以上命中，短句 1 个也算；再按「越近越算」「越重要越算」打分；
4. 取前 4 条，拼成 prompt 里一小段 `[你记得的事（以前留下的，不是他刚说的）]`。

进 prompt 的位置：`src/bridge.js` 的 `extra`（在「你自己的想法」后面）。
捞不到就什么都不加，不硬塞。

### digest —— 睡前把今天压成一两条

`src/memory-digest.js`，由 `scripts/mind-run.mjs` 在 22:00 之后自动跑（一天一次）：

- 素材：最近 24 小时的聊天、她自己的想法、吃了什么、评论区说的话、约定、被摸头、明天的打算；
- 一次模型调用，让她自己写 1～4 件事 + 0～3 条事实，只接受 JSON；
- 解析不出来 / 模型失败 → 不写盘、不标记完成，下次还能补；
- 写进 episodes / facts，并在 `data/memory/state.json` 记 `lastDigestDay`。

## 进 prompt 的地方

- 聊天（`src/bridge.js`）：`[你记得的事]` 拼进 extra
- 独处（`src/mind.js`）：`[最近几天发生过的事]` 进想法 prompt 和对话 prompt
- 房间（http://127.0.0.1:8770）：抽屉里「记忆」页，能看到她记得的事和知道的事实

## 划掉记错的东西

记忆是文件，但不用手改文件：

- 房间抽屉「记忆」页：每条事实 / 每件事右边有个 ×，点了确认就删；删除记进 `data/memory/changes.jsonl`（审计）。
- 命令行：

```bash
node --env-file-if-exists=.env.qq scripts/memory.mjs --list          # 每条情景后面带时间戳
node --env-file-if-exists=.env.qq scripts/memory.mjs --forget-fact "爸爸:爱吃的"
node --env-file-if-exists=.env.qq scripts/memory.mjs --forget-episode "1793723111548:答应不天天打游戏"
```

删掉之后 recall 不会再捞到它。

## 手动看 / 手动整理

```bash
cd ~/wechat-bridge
node --env-file-if-exists=.env.qq scripts/memory.mjs --list
node --env-file-if-exists=.env.qq scripts/memory.mjs --recall "西瓜"
node --env-file-if-exists=.env.qq scripts/memory.mjs --digest            # 今天已整理就跳过
node --env-file-if-exists=.env.qq scripts/memory.mjs --digest --force    # 重跑今晚
node --env-file-if-exists=.env.qq scripts/memory.mjs --stats
```

## 边界

- **是记录，不是回忆**：她看到的是「11/04 爸爸给装了游戏」，不是当时的感觉。
- **检索是二字匹配，不是语义**：换个说法可能捞不到（「背诗」捞不到「蒹葭」）。
- **一天一次会漏**：白天的小事如果当晚没被写进去，就永远没有。
- **容量**：episodes 最多 600 条，满了丢最旧的；facts 不删，新的盖旧的。
