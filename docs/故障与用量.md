# 故障、用量、评测

三件都是「别等出事才知道」：她坏掉时会说话、花了她多少钱有数、改了 prompt 有办法验。

## 故障：她坏掉了会自己说

`src/health.js` + `src/notify-send.js` + `scripts/notify.mjs`

- 桥接 / 想事循环 / 摸头生成 各自往 `data/health.json` 记成功或失败（组件：chat、mind、pat、video、qzone）。
- 同一个组件**连续失败 3 次**、且距上次喊人超过 6 小时，就往爸爸 QQ 发一条：
  `小鲸这边卡住了：想事连续 3 次失败（DSH 退出码 1）。你要是看到这条，去 logs/mind.log 看一眼。`
- 发出去才记「喊过了」；发不出去，下一条失败还会再试。
- 成功一次就把该组件的连续失败清零。
- 房间页右上角状态卡里有一行「她的脑子：正常 / 卡住了（想事 ×3）」，就是 `health.status()`。
- 喊人是子进程跑 `scripts/notify.mjs`，它自己读 `.env.qq` 里的 `QQ_ALLOW_LIST[0]`，走 `scripts/qq-action.mjs` 的私聊；`--dry-run` 只打印不发送，调试用。

边界：它只报「连续失败」，不报单次抖动；失败阈值和冷却都可以在 `src/health.js` 改常量。

## 用量：今天调了几次模型

`src/usage.js` + `src/dsh.js` 的 `usage` 钩子

- 每次 dsh 调用结束（成功/失败/超时）记一行到 `data/usage/usage.jsonl`：`{at, day, kind, ms, inChars, outChars, ok}`。
- kind 区分来源：聊天、想事（含睡前整理）、摸头那句、约定那句、看视频等。
- 房间页状态卡里有一行「今天：聊天 12 · 想事 38 · 摸头 4」；`GET /api/usage` 给原始汇总。
- 只做「次数 / 字数 / 耗时」，不做精确费用：价格会变，按字数粗估一个 token 数量级就够了（`estTokens = chars / 1.6`）。

## 预算：每天最多调多少次

`src/budget.js`

- 每天模型调用次数上限默认 800（`createBudget({limit})` 可改），到 80%（640 次）发一次 QQ 提醒：
  `小鲸今天的模型调用已经用了 660/800 次。再花下去可能要等明天，我先省着点。`
- 一天只提醒一次；超过上限后**只砍非必要调用**：想事、睡前整理、摸头那句、约定那句——聊天照常回。
- 房间状态卡那行「今天：… · 已用 37/800」，接近上限变黄、超了变红；`GET /api/usage` 带 `budget`。
- 阈值和冷却都在 `src/budget.js` 的常量里。

## 维护：日志轮转 / 裁剪 / 备份

`scripts/maintenance.mjs`，由 `scripts/mind-run.mjs` 每天 04:00 之后第一轮自动跑一次（记在 `data/maintenance.json`）：

- `logs/*.log` 超过 10MB 才轮转（rename 成 `.log.1`，最多留 2 代）；
- 只裁 `data/douyin/seen.jsonl`、`data/qq/audit.jsonl` 到最后 5000 行（先存 `.bak`），**不碰** `data/memory`、`data/mind`、`data/scrapbook`；
- 打包备份 `data/memory`、`data/mind/{memory,stream}.jsonl`、`data/scrapbook`、`persona.md`、`persona.traits.json`、`docs/记忆.md` 到 `backups/YYYY-MM-DD.tgz`，保留最近 7 份。

手动跑 / 看计划：

```bash
node scripts/maintenance.mjs --dry-run    # 只看会做什么，不动
node scripts/maintenance.mjs              # 真跑一次
```

边界：备份在本机同一个盘上，防手滑不防硬盘坏；抖音浏览器的 profile（2.4G）不在备份里，也不清。

## 评测：她的话有没有变形

`src/eval-checks.js` + `scripts/eval-behavior.mjs`

- 检查函数（纯函数、单测覆盖）：句子长度/解释腔/客服腔、带火气、是否贴题（与视频 brief 的中文 bigram 重合）、是否复读、是否漏系统标记（【此刻】【语音】等）。
- 真模型跑 5 个固定场景：普通闲聊、被问「你干嘛呢」、「今天好累」、接一句半截话、带视频 brief 的评论回复。

```bash
cd ~/wechat-bridge
npm run eval                 # 5 轮真模型，失败 exit 1
npm run eval -- --dry        # 只打印场景和检查项，不联网
```

每次改人设 / prompt / 视频回复逻辑之后跑一遍，比等爸爸踩出来快。

边界：5 个场景只能兜住常见变形，不能证明「像人」；检查项是硬的（长度、火气、复读、漏标记），不管语气好不好。
