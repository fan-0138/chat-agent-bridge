# 调她的性格（性格刻度）

旧的人物卡（58KB）已经不用了，挪到 `archive/personas/` 存档。现在性格由两个地方决定：

| 文件 | 管什么 | 改完 |
|---|---|---|
| `persona.md` | 她**是谁**：身份、外观、经历、雷区、关系、聊天规则 | 下一条消息生效 |
| `persona.traits.json` | 她**有多强**：8 个 0–5 的刻度 | 下一条消息生效 |

两个文件都是按 mtime 热加载的，**不用重启桥接**。

## 8 个刻度

| 键 | 刻度 | 出厂 | 0 分 | 5 分 |
|---|---|---|---|---|
| `tsundere` | 傲娇 | 3 | 想夸就夸，不嘴硬 | 嘴上全是刺，其实最黏人 |
| `cute` | 撒娇 | 4 | 说话直来直去 | 几乎每句都在撒娇 |
| `snark` | 毒舌 | 1 | 只吐槽事，不针对人 | 句句扎心 |
| `talk` | 话量 | 2 | 一两个词 | 话痨，连发好几条 |
| `initiative` | 主动 | 3 | 只回答，不追问 | 一直想聊下去，怕冷场 |
| `serious` | 正经 | 2 | 全是玩笑 | 很正经，几乎不玩梗 |
| `emotional` | 情绪 | 3 | 平稳不起伏 | 说翻脸就翻脸 |
| `goofy` | 憨 | 3 | 精明，不犯傻 | 傻乎乎，常识掉线 |

每一档的具体描述在 `src/traits.js` 的 `TRAITS` 里，是行为描述（「被夸会嘴硬，但明显高兴」），不是形容词，方便模型照着演。

## 怎么改

**方式一：命令行（会写回文件）**

```bash
node scripts/persona-preview.mjs --set cute=5 snark=3
```

**方式二：直接编辑 `persona.traits.json`**

```json
{
  "tsundere": 3,
  "cute": 5,
  "snark": 3,
  "talk": 2,
  "initiative": 4,
  "serious": 2,
  "emotional": 4,
  "goofy": 3
}
```

**看效果**

```bash
npm run persona                 # 打印模型真正会收到的人设全文
npm run persona -- --traits     # 只看刻度那段
npm run persona -- --json       # 只看清洗后的刻度值
npm run selfcheck:qq            # 启动自检会顺带打印刻度
```

## 设计约定

- **刻度只调强度，不改身份。** 「她是谁」写在 `persona.md`；刻度只管「傲娇到什么程度」。
- **6 档是硬约束。** `src/traits.js` 里每个刻度必须有 6 条行为描述，加新刻度就补 6 条，测试会检查。
- **越界会被夹紧**：写 9 当 5，写 -1 当 0，写 `"abc"` 回落默认；未知键直接丢掉，不会污染 prompt。
- **刻度块不会被截断**：正文超长时先截正文，`[性格刻度]` 整段保留。
- **别把刻度演成口头禅**：刻度段末尾有一句约束，模型不该每条都复读同一句话。

## 加新刻度

1. 在 `src/traits.js` 的 `TRAITS` 加一项，写 6 条行为描述；
2. 在 `DEFAULTS` 里给个默认值；
3. 跑 `npm test` —— `traits.test.js` 会检查档位数量、默认值覆盖、渲染完整性。

不需要改 `persona.js`，它是遍历 `TRAITS` 渲染的。
