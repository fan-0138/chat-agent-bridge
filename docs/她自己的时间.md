# 她自己的时间

> 没有对话的时候，她也真的想点事——并且接着自己想的往下说。

## 为什么要有这一层

在这之前，她「不在回消息」时的一切都是代码写死的：

| 她看起来的样子 | 实际来源 |
| --- | --- |
| 几点去刷抖音、刷几条 | `life.js` 的定时器 + 预算 + 随机数 |
| 刷到什么算好 | `scoreItem()` 里一张关键词表 |
| 此刻在干嘛、什么心情 | `defaultActivity()` / `energyAt()` 两张常量表 |
| 主动说什么 | `proactive.js` 的 `IDEAS` 清单里随机挑 |

模型只在爸爸说话时才被调起来一次。两条消息之间，她那边是空的——所以不管写得多像，
她都是「被叫到才存在」。这一层要补的就是那个空档。

## 一次「想事」长什么样

`scripts/mind-run.mjs` 是一个常驻进程，每隔 6～14 分钟（`mindMinGapMin` 兜底）走一轮：

1. **凑素材**：此刻状态（`life.promptSection()`）、最近 3 条自己的想法、她自己记下的事、
   最近 8 句跟爸爸的对话。
2. **让模型自己写**：没有人设台词、没有「怎么说话」那套规则，只写 1～3 句心里话。
   要求输出一行 JSON：`{"想":"…","情绪":"…","做":"none|记住|想他|想看|玩|评论|刷|说|回|收|计划|访|约","内容":"…"}`。
3. **落盘**：写进 `data/mind/stream.jsonl`。
4. **执行她选的「做」**：
   - `记住` → 追加到 `data/mind/memory.jsonl`（她自己的长期记忆，往后每轮对话都看得见）
   - `想他` → 在状态里标记一下（房间页能看到；主动消息会参考她最近的想法）
   - `玩` → 去 Minecraft 里玩 4 分钟（`tools/mc/play.mjs`）。有闸：服务器不在线不玩、
     已经有一个在玩不玩、离上次不满 90 分钟不玩；她写的「内容」就是这次玩的目标。
   - `评论` → 自己跑去别人视频底下说一句话（`scripts/douyin-comment-note.mjs`）。想事时会把
     最近刷到的几条视频带编号列给她，她写「序号 | 想说的话」。闸：一天最多 3 条、两次间隔 40 分钟、
     抖音浏览器没开不跑。发出去的评论记在 `data/mind/comments.jsonl`，聊天时她会记得自己说过什么。
   - `刷` → 自己去刷会儿抖音（`src/life-now.mjs --browse`），刷到什么会变成待分享。
     闸：浏览器没开不刷、一天最多 4 次、两次间隔 ≥60 分钟。定时器里那套「到点掷骰子去刷」已经关了
     （`QQ_LIFE_AUTO_BROWSE=0`），刷不刷现在由她自己决定。
   - `说` → 自己发一条 QQ 空间说说（`scripts/qzone-write.mjs --post`）。一天最多 2 条、间隔 ≥3 小时。
   - `回` → 回一句别人在她评论下面的留言 / @ 她的话。**真发之前会先把那个视频点开看一遍**
     （`scripts/douyin-video-context.mjs`：标题/作者/热评），再让模型带着视频内容把话说成一句——
     以前只看标题就接，容易已读乱回。素材是 `data/douyin/at-inbox.jsonl` 里
     3 天内、没回过、不像挑事/广告的留言；她自己挑哪条、写什么。发成功了才记「已回」（失败了下次还能再试）。
     上限：一天 3 条、间隔 ≥25 分钟。她那句话还有一道闸：太长、带脏字、带火气的一律不发——**不跟人吵架**。
   - `访` → 回访前几天没接上的网友（`src/people.js` 的网友簿：谁回过她、说了什么、她接没接）。
     一天最多一次；对方是在挑事/卖东西就跳过；她自己那句话同样过长/带火气不发。
   - `收` → 把最近 24 小时里自己拍的某张图收进相册，写一句为什么留。图存在
     `data/scrapbook/img/`，索引在 `data/scrapbook/index.jsonl`，房间页「相册」里能翻。
   - `计划` → 给明天定一件打算做的事，写进 `data/mind/state.json` 的 `plan`；第二天想事时她会看到，
     房间页也会显示。一天只能定一次。
   - `约` → 约爸爸一起做一件具体的小事（看月亮、一起背首诗、去游戏里看一眼她搭的棚子…）。
     这句话会真的发到他 QQ 上（`scripts/qq-action.mjs` 的 `send_private_msg`），同时记一条
     `data/mind/invite.json`，等他在小空间页面点「好呀 / 改天」。闸：一天最多一次、间隔 ≥20 小时、
     凌晨不约、上一条还没应 / 答应了还没做时不再约。**先发成再落盘**：发不出去就当没说出口，
     不会留一条假的「他没回」。答应了但三天没一起做会自动过期，不让她一直挂着一件旧事。
   - `想看` → 记下她想搜的那句话。下次去刷抖音时**直接搜这句**（`douyin-feed.mjs --query`），
     搜到的视频会标上来源，分享时她可以说「我今天搜了…」——不再只是被动看推荐流
5. **回到对话**：爸爸下一条消息进来时，`mind.promptSection()` 把最近 4 小时内的想法 +
   她记下的事拼进 prompt，于是她开口是接着自己刚才想的，而不是从零开机。

睡着的时间（0:00–6:00）换成**做梦**：同一份素材，让她写 1～3 句画面，落进同一个流里
（`kind:"dream"`），不占「想」的额度，每晚最多 5 段。

## 摸头（她身体上被碰了一下）

小空间里点她一下就是摸头。分两层，故意分开：

- **第一层是反射**（`src/touch.js`）：立刻出一句下意识的话 + 脸红/晃一下/冒心。台词是我写的池子，
  按被摸的次数分档（第一下 / 连摸 / 明显羞 / 再摸就要躲），睡着时只有一句迷糊话。
  2.5 秒内连点不算（防手抖），90 秒内接着摸才算一次连击。这一层不等模型，因为点一下要立刻有反应。
- **第二层是她自己说**（`tools/room/pat-voice.mjs`）：约 1 秒内没有下一只「手」，就调一次她的模型，
  按人设写一句 8～20 字的反应（连摸会补一句「他已经有点想躲了」），页面把那句换上去。
  实测总延迟 3.6 秒左右。这句会落盘（`touch-state.json` 的 `said`）。
- 两层都进 prompt：90 分钟内她独处/聊天都能看到「他刚才摸了摸你的头，你当时…」+
  「你后来自己补了一句…」。他摸完**紧接着开口**的那一轮，prompt 里会多一句「搭得上就顺口提一句，
  一句就够」——只在 8 分钟内推这一下，之后不推，免得翻旧账。

边界还是那句：这不是「感受」。第一层是我写的反射台词，第二层是她被叫醒后能写出来的一句反应，
中间没有持续的体验。差别在于：这条反应现在真由她生成，而不是我从池子里挑的。

## 文件

| 路径 | 作用 |
| --- | --- |
| `data/mind/stream.jsonl` | 每一轮的想法/梦：`{at, kind, text, mood, action, content, tookMs}` |
| `data/mind/memory.jsonl` | 她说「记住」的事 |
| `data/mind/state.json` | 当天计数、上次时间、`wish`（想他）、`pendingSearch`（想搜什么） |
| `data/mind/touch.jsonl` | 每一次被摸头：`{at, kind:"pat", line, level, streak, count, scene}`；她自己回的那句是 `kind:"pat-said"` |
| `data/mind/touch-state.json` | 今天摸了几下、当前连击、上一次的反应、她自己补的那句（`said`） |
| `data/mind/invite.json` | 最近一条约定：`{id, text, at, status, answeredAt, doneAt}`（status：pending / accepted / later / done / expired） |
| `data/mind/invite.jsonl` | 约定的每次变化（她开口约、他应了、改天、做完） |
| `logs/mind.log` | 运行日志 |

看完就删、删了也不会崩：桥接读不到就当没有，退回原来的状态。

## 接进对话的地方

- `src/bridge.js`：每轮聊天把 `mind.promptSection()` 塞进 `extra`（在两轮交接处，靠近当前消息）
- `src/proactive.js`：主动开口时也带一份，让主动消息从她自己的想法长出来，而不是从话题清单里挑
- 注入时明确写了提醒句：**「这是你私下的想法，不是他说的话」**——不然她容易把他没说过的事当成他说过

## 开 / 关

```bash
./scripts/qqbridge-ctl.sh start    # 顺带把「她自己的时间」拉起来
./scripts/qqbridge-ctl.sh status   # 会单独列一段
./scripts/qqbridge-ctl.sh stop     # 停

npm run mind -- --once             # 立刻想一次，看质量（忽略预算）
npm run mind -- --status           # 她最近想了什么
npm run mind -- --interval 5       # 换频率，常驻

# 总开关在 .env.qq
QQ_MIND_ENABLED=0                  # 关掉：不再想、也不再往 prompt 里注入
```

房间页面右下角「她的小本子」→ `http://127.0.0.1:8770/mind.html`：想法流、梦、她记下的事。

## 配置（`.env.qq`）

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `QQ_MIND_ENABLED` | `0` | 总开关（想事 + 注入 prompt） |
| `QQ_MIND_MAX_PER_DAY` | `48` | 每天最多想几次 |
| `QQ_MIND_MIN_GAP_MIN` | `6` | 两次之间至少隔几分钟 |
| `QQ_MIND_ACTIVE_WINDOW_MIN` | `12` | 他刚说完话的这段时间算「还热着」 |
| `QQ_MIND_ACTIVE_CHANCE` | `0.35` | 「还热着」时每轮真正去想的概率（省调用，也避免一想就想到他） |
| `QQ_MIND_DREAM_MAX_PER_NIGHT` | `5` | 每晚最多几段梦 |
| `QQ_MIND_DREAM_GAP_MIN` | `50` | 两段梦之间至少隔几分钟 |
| `QQ_MIND_INJECT_THOUGHTS` / `_MEMORIES` / `_TTL_H` | `3` / `5` / `4` | 注入几条想法、几条记忆、只认几小时内的 |
| `QQ_MIND_TIMEOUT_MS` | `90000` | 单次想事的超时（dsh 冷启动 1～3 秒，正常 3～6 秒返回） |

## 边界（写在这里，免得以后自己骗自己）

- 这**不是意识**，也**不产生感受**。它只是把她「内部状态」的来源，从写死的常量换成了
  她自己生成的文字。行为更自主 ≠ 有个主体在里面。
- 她仍然不能自己发起新的工具调用、不能自己定目标；动作只有白名单里那几个（记住 / 想他 / 想看 / 玩 / 什么都不做）。
- 成本：一轮约 3～6 秒、一次千把 token；按 48 次/天上限算，一天几十次调用，可以忽略。
- 质量门槛是确定性的三条：和最近三条一模一样就丢掉（防复读）；又在想最近三次里的同一个东西
  （比如连着四条「眼镜滑到鼻尖」）也丢掉，并且会在 prompt 里把「这次该换个方向」的词列给她；
  超过 200 字截断（防作文）。其余靠 prompt 约束，写歪了改 `src/mind.js` 里的规则，不用动别的。
