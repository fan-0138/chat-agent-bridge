# 她自己的时间

> 没有对话的时候，她也真的想点事——并且接着自己想的往下说。

## 为什么要有这一层

在这之前，她「不在回消息」时的一切都是代码写死的：

| 她看起来的样子 | 实际来源 |
| --- | --- |
| 几点去刷抖音、刷几条 | `life.js` 的定时器 + 预算 + 随机数 |
| 刷到什么算好 | `scoreItem()` 里一张关键词表 |
| 此刻在干嘛、什么心情 | `defaultActivity()` / `energyAt()` 两张常量表 |
| 主动说什么 | `proactive.js` 的 `IDEAS` 清单里随机挑 |

模型只在爸爸说话时才被调起来一次。两条消息之间，她那边是空的——所以不管写得多像，
她都是「被叫到才存在」。这一层要补的就是那个空档。

## 一次「想事」长什么样

`scripts/mind-run.mjs` 是一个常驻进程，每隔 6～14 分钟（`mindMinGapMin` 兜底）走一轮：

1. **凑素材**：此刻状态（`life.promptSection()`）、最近 3 条自己的想法、她自己记下的事、
   最近 8 句跟爸爸的对话。
2. **让模型自己写**：没有人设台词、没有「怎么说话」那套规则，只写 1～3 句心里话。
   要求输出一行 JSON：`{"想":"…","情绪":"…","做":"none|记住|想他","内容":"…"}`。
3. **落盘**：写进 `data/mind/stream.jsonl`。
4. **执行她选的「做」**：
   - `记住` → 追加到 `data/mind/memory.jsonl`（她自己的长期记忆，往后每轮对话都看得见）
   - `想他` → 在状态里标记一下（房间页能看到；主动消息会参考她最近的想法）
5. **回到对话**：爸爸下一条消息进来时，`mind.promptSection()` 把最近 4 小时内的想法 +
   她记下的事拼进 prompt，于是她开口是接着自己刚才想的，而不是从零开机。

睡着的时间（0:00–6:00）换成**做梦**：同一份素材，让她写 1～3 句画面，落进同一个流里
（`kind:"dream"`），不占「想」的额度，每晚最多 5 段。

## 文件

| 路径 | 作用 |
| --- | --- |
| `data/mind/stream.jsonl` | 每一轮的想法/梦：`{at, kind, text, mood, action, content, tookMs}` |
| `data/mind/memory.jsonl` | 她说「记住」的事 |
| `data/mind/state.json` | 当天计数、上次时间、`wish` |
| `logs/mind.log` | 运行日志 |

看完就删、删了也不会崩：桥接读不到就当没有，退回原来的状态。

## 接进对话的地方

- `src/bridge.js`：每轮聊天把 `mind.promptSection()` 塞进 `extra`（在两轮交接处，靠近当前消息）
- `src/proactive.js`：主动开口时也带一份，让主动消息从她自己的想法长出来，而不是从话题清单里挑
- 注入时明确写了提醒句：**「这是你私下的想法，不是他说的话」**——不然她容易把他没说过的事当成他说过

## 开 / 关

```bash
./scripts/qqbridge-ctl.sh start    # 顺带把「她自己的时间」拉起来
./scripts/qqbridge-ctl.sh status   # 会单独列一段
./scripts/qqbridge-ctl.sh stop     # 停

npm run mind -- --once             # 立刻想一次，看质量（忽略预算）
npm run mind -- --status           # 她最近想了什么
npm run mind -- --interval 5       # 换频率，常驻

# 总开关在 .env.qq
QQ_MIND_ENABLED=0                  # 关掉：不再想、也不再往 prompt 里注入
```

房间页面右下角「她的小本子」→ `http://127.0.0.1:8770/mind.html`：想法流、梦、她记下的事。

## 配置（`.env.qq`）

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `QQ_MIND_ENABLED` | `0` | 总开关（想事 + 注入 prompt） |
| `QQ_MIND_MAX_PER_DAY` | `48` | 每天最多想几次 |
| `QQ_MIND_MIN_GAP_MIN` | `6` | 两次之间至少隔几分钟 |
| `QQ_MIND_ACTIVE_WINDOW_MIN` | `12` | 他刚说完话的这段时间算「还热着」 |
| `QQ_MIND_ACTIVE_CHANCE` | `0.35` | 「还热着」时每轮真正去想的概率（省调用，也避免一想就想到他） |
| `QQ_MIND_DREAM_MAX_PER_NIGHT` | `5` | 每晚最多几段梦 |
| `QQ_MIND_DREAM_GAP_MIN` | `50` | 两段梦之间至少隔几分钟 |
| `QQ_MIND_INJECT_THOUGHTS` / `_MEMORIES` / `_TTL_H` | `3` / `5` / `4` | 注入几条想法、几条记忆、只认几小时内的 |
| `QQ_MIND_TIMEOUT_MS` | `90000` | 单次想事的超时（dsh 冷启动 1～3 秒，正常 3～6 秒返回） |

## 边界（写在这里，免得以后自己骗自己）

- 这**不是意识**，也**不产生感受**。它只是把她「内部状态」的来源，从写死的常量换成了
  她自己生成的文字。行为更自主 ≠ 有个主体在里面。
- 她仍然不能自己发起新的工具调用、不能自己定目标；动作只有白名单里那三个（记住 / 想他 / 什么都不做）。
- 成本：一轮约 3～6 秒、一次千把 token；按 48 次/天上限算，一天几十次调用，可以忽略。
- 质量门槛是确定性的三条：和最近三条一模一样就丢掉（防复读）；又在想最近三次里的同一个东西
  （比如连着四条「眼镜滑到鼻尖」）也丢掉，并且会在 prompt 里把「这次该换个方向」的词列给她；
  超过 200 字截断（防作文）。其余靠 prompt 约束，写歪了改 `src/mind.js` 里的规则，不用动别的。
