## 三、踩过的坑（会重复踩的）
- **日志时间是 UTC**，比本地少 8 小时，别按本地时间找日志
- **ask-xixi 必须自己加载 `.env.qq`**，否则白名单是空的，消息被当陌生人静默忽略（已修在脚本里）
- 抖音播放地址带 rkey 时效，拿到就下，别拖
- **她的「身体」有两层**：日常模拟身体（工位/雨/手僵）和 MC 里那具（xixi）。两边共用一套叙事，
  所以游戏里挨打她当成自己挨打；提示词里必须划边界，否则睡前整理会把「游戏里的伤」写成现实事实
- `present`/文件路径：会话 cwd 是 `~/Documents/deepseek`，指到她那边的东西要用绝对路径
- 公开仓库根目录的 README/package.json 来自 `publish/`，别在 clone 里直接改
- UVR5 分人声时个别文件报 `Audio buffer is not finite everywhere`，换 HP5 模型能救大部分；救不回就跳过
- `openBrowser()` 不显式传 `cdpUrl` / 不加载 `.env.qq` 时，会误判没浏览器去新起一个，报 `ProcessSingleton` 锁冲突
- 抖音评论楼中楼：**只能走界面**（点回复 → 输入 → 回车），接口那条路不落地
- 回车之后**别信页面文字**判断发没发出去（列表不刷新会误判）→ 拉 `comment/list` 看 `reply_comment`；短间隔连发可能被静默吞掉
- `comment/list` 里的 `reply_comment` 有时候是**数组**、有时候是对象，两种都要处理
- 用 CDP 复用旧页面跑 `evaluate` 会挂住（踩过一次，卡 4 分钟）；探针脚本一律新开页、用完关
- **发布完必须回创作者中心核对「作品(N)」+ 状态**：脚本 `clicked:true` 也可能没真发出去（今天第一次就没生效，第二次才成）
- 一天别超两条作品（爸爸说多了限流）
- **MC 判「头在水里」**：要跟 `perception.mjs` 一样用「脚下整格 +1」；用 `position.offset(0,1.6,0)` 会落到水面以上的空气里，永远判不出水
- **`bot.oxygenLevel` 不可信**：实测一直卡在 20（人在岸上也是 20），拿它当救援条件会把人从陆地上每 10 秒往家 tp 一次；只当信息打印
- **泡水/活着这类周期性状态别只「此刻采样」**：反射会跳，跳一下头就露出来一瞬，3 秒采一次容易全采在那一口气上 → 要累计时长
- **`mc-ctl.sh` 的 launchd 分支不可靠**：从我这边 shell 里 bootstrap 出来的 mcserver/mcbody 任务过一会儿就从 gui 域消失（`kickstart` 报 Could not find service）→ 直接 nohup 起
